## 3. Project Summaries

### 3.1 Aahar Nearby
- **Product Classification**: Hyperlocal Mobile Application & Real-Time Discovery Platform.
- **Problem Space**: Working professionals and office employees waste significant time every morning and lunch hour wondering *"Aaj kya khana hai?"* (What to eat today?). Local restaurants change their daily specials and thalis daily, but lack an instant, zero-friction mechanism to publish menus without expensive aggregator commissions.
- **Engineered Solution**: A 3-role mobile application (Diner, Hotel Owner, Admin) allowing restaurant owners to publish daily menus in 15 seconds, enhanced by an AI menu formatting simulator. Diners discover nearby menus sorted by distance, price, dietary preference (Veg / Non-Veg), and receive real-time menu notifications.
- **Primary Stack**: Flutter (Dart 3+), Firebase Auth, Cloud Firestore, Firebase Storage, Geolocator, OneSignal Flutter, Google Fonts.
- **Verifiable Status**: Complete 10-screen luxury emerald UI system, multi-role state isolation, live device notifications verified, and 12-phase production test suite completed.
- **Detailed Case Study**: See [CASE_STUDY_AAHAR_NEARBY.md](file:///e:/VEYTRIX%20TECH/CASE_STUDY_AAHAR_NEARBY.md).

### 3.2 DateInvite
- **Product Classification**: Interactive Web Application & Micro-Invitation Platform.
- **Problem Space**: Asking someone out over text messaging is dull, impersonal, and frequently results in ambiguous scheduling. Traditional invitation tools are built for large weddings or formal corporate webinars, requiring tedious signups and rigid formats.
- **Engineered Solution**: A two-sided, mobile-first invitation web app where creators generate unique, personalized invitation links in under 30 seconds without creating an account. Recipients experience a playful, animated proposal with an interactive questionnaire covering date activities, times, and vibes. Responses are securely saved to Supabase (with Row Level Security protecting creator privacy) and trigger instant structured email notifications via Resend.
- **Primary Stack**: Next.js 14 (App Router), React 18, TypeScript, Supabase (PostgreSQL, RLS), Tailwind CSS, Framer Motion, Resend API.
- **Verifiable Status**: Production build verified, end-to-end simulation passed, security & RLS policies live-audited, zero email leakage confirmed.
- **Detailed Case Study**: See [CASE_STUDY_DATEINVITE.md](file:///e:/VEYTRIX%20TECH/CASE_STUDY_DATEINVITE.md).
